# ⚔ Anime Battle

A mobile-first friend challenge website inspired by shareable quiz experiences.

## Features
- Create a 10-question anime challenge
- Generates a shareable challenge URL
- Friends answer on their own device
- Anime-sync scoring and ranks
- Mobile share button
- Local leaderboard
- No login required
- Pure HTML, CSS and JavaScript

## Run
Open `index.html` directly or deploy the repository as a static website.

## GitHub Pages
Repository Settings → Pages → Deploy from branch → `main` → `/(root)`.

## Note
This version keeps the answer key inside the challenge URL and stores leaderboard results in browser localStorage. A future backend/database can provide a global cross-device leaderboard.
